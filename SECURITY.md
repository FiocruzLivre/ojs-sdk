# Security Policy

## Supported Versions

| Version | Compatible with | Supported          |
|---------|------------------|---------------------|
| 0.2.x   | OJS 3.4          | :white_check_mark: |
| 0.1.x   | OJS 3.3          | :x:                 |

## Reporting a Vulnerability

Please **do not open a public issue** to report security problems.

Use GitHub's private reporting feature: on this repository's **Security**
tab, click **Report a vulnerability**. Only the maintainer team will have
access to the report.

Please include, if possible, the affected version, steps to reproduce the
issue, and the expected impact. We aim to respond within 10 business days.
